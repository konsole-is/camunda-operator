# Kubebuilder Bootstrap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bootstrap `camunda-operator` as a compilable kubebuilder v4 project with all 19 CRD types
and 17 controller stubs scaffolded.

**Architecture:** Run `kubebuilder init` then `kubebuilder create api` once per CRD. 17 CRDs get
both a type file and a controller stub; 2 preset CRDs get types only. No implementation logic —
this plan produces skeleton structure only.

**Tech Stack:** kubebuilder v4.13.1, Go 1.26.1, controller-runtime, sigs.k8s.io/controller-tools

**Working directory:** All commands run from
`/home/aegir/Documents/personal/camunda-stack/camunda-operator/`

## Task 7: Generate code and manifests, run final verification

`make generate` runs `controller-gen` to produce `zz_generated.deepcopy.go` for all types.
`make manifests` produces the CRD YAML manifests under `config/crd/bases/`.

- [ ] **Step 1: Install controller-gen and run code generation**

```bash
make generate
```

Expected: exits 0. Creates `api/v1/zz_generated.deepcopy.go`. If it fails with
"controller-gen: command not found", the Makefile installs it automatically — check that
`$(GOPATH)/bin` or `$(HOME)/go/bin` is on your `$PATH`.

- [ ] **Step 2: Generate CRD manifests**

```bash
make manifests
```

Expected: exits 0. Populates `config/crd/bases/` with one YAML file per CRD, e.g.
`core.camunda.io_camundaclusters.yaml`.

- [ ] **Step 3: Verify final build**

```bash
go build ./...
```

Expected: exits 0.

- [ ] **Step 4: Verify tests compile**

```bash
go test ./... -run ^$
```

Expected: exits 0. The `-run ^$` pattern matches no test names, so nothing executes —
this just confirms the test files compile. Full envtest-based tests require the test
binaries set up by `make test` and are out of scope for this bootstrap.

- [ ] **Step 5: Final commit**

```bash
git add .
git commit -m "chore: generate deepcopy and CRD manifests

All 19 CRD types generated. 17 controller stubs registered in cmd/main.go.
Operator builds and compiles clean."
```
